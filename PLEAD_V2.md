# PLEAD-V2 experiments

Run from the repository root with the existing CAP-NEO GPU environment. Both experiments run under one command per dataset and write independent output directories. The experiment uses 15 corruptions including ImageNet-C `zoom_blur`, severity 5, seeds 1234, 2020 and 9999, and batches of 64 with 512 adaptation arrivals per stream. Every stream starts with fresh adaptation state.

```bash
CUDA_VISIBLE_DEVICES=0 python -u run_plead_v2.py --dataset cifar10-c --data /data/user3/chenc/datasets/CIFAR-10-C --output plead_v2_results/cifar10-c
CUDA_VISIBLE_DEVICES=0 python -u run_plead_v2.py --dataset cifar100-c --data /data/user3/chenc/datasets/CIFAR-100-C --output plead_v2_results/cifar100-c
CUDA_VISIBLE_DEVICES=0 python -u run_plead_v2.py --dataset imagenet-c --data /data/user3/chenc/datasets/ImageNet-C --output plead_v2_results/imagenet-c
```

Use the same command and output directory to reuse completed streams. `--smoke` selects Gaussian noise and seed 2020. Give smoke its own output directory. To run the tests on the server, use `python -m unittest discover -s tests -p 'test_*.py'`. CIFAR-10-C uses the original pinned `nateraw` checkpoint and the existing ViT processor. CIFAR-100-C uses the pinned CIFAR-100 checkpoint and its processor. ImageNet-C uses the original timm ViT-Base and ImageNet-C preprocessing. These are the same assets as the CAP-NEO runner.

The ablation evaluates the original PLEAD (`cap_neo`), the new ridge fit, ridge with Cross-View, ridge with the split-bank gate, and full PLEAD-V2. The adaptation indices and order use the natural stream sampler. Balanced validation draws 50, five and one distinct held-out images per class for CIFAR-10-C, CIFAR-100-C and ImageNet-C, respectively. Smoke also compares original PLEAD and NEO logits, metrics and state history to the legacy evaluator on the same streams.

The single-view variants use the A margin and consistency 1. In Cross-View variants, a deterministic horizontal flip after preprocessing produces B. The frozen model computes the flipped view once per adaptation batch, shared by the variants that need it. Prediction and validation use A. The bank stores raw logits and projected features for arrived samples. The two gate fits take alternating indices of that bank. Every method uses the same original shrinkage formula applied to its own per-sample residuals.

The long-tail experiment compares original NEO with full PLEAD-V2 only. It permutes class ranks once per seed and uses normalized `rho**(-k/(C-1))` weights. The sampler systematically rounds target counts, samples distinct images, and logs any capacity-limited count redistribution. It fails if the remaining population cannot supply the total distinct quota. The balanced and prior-matched validation sets have the same size and are disjoint from each other and adaptation. Matched validation samples the nominal long-tail distribution. Actual ordered indices, label counts, class rank, target prior, missing classes and redistribution are recorded. Labels enter only sampling and scoring. This DART-inspired fixed-budget protocol draws on exponential long tails and uses its own split, adaptation budget and paired evaluation. DART's original full long-tail test sets and its online IR protocol for large class spaces use different evaluation settings. [DART paper](https://arxiv.org/abs/2411.15204)

Each dataset directory contains `ablation_per_stream.csv`, `ablation_summary.csv`, `ablation_table.tex`, `longtail_per_stream.csv`, `longtail_summary.csv`, `longtail_table.tex` and `longtail_accuracy.pdf`. Per-stream JSON files save split manifests and per-batch κ, λ, γ, Neff, Sxx, correlation and fallback reasons. A zero gate caused by a failed split fit counts as a fallback. A zero gate from the ordinary uncertainty formula is captured by `gate_off_rate`. For nonapplicable diagnostics the CSV field is blank.

Time is synchronized GPU inference time, in seconds. Method time includes adapter calls and the method's share of one B forward per adaptation batch if used. Total inference time adds the common A forwards and excludes image loading and metrics. GPU peaks are observed allocated memory in MiB and include co-resident methods. For summary tables, each seed contributes its mean over corruptions. Gain is a paired Top-1 difference in percentage points against original PLEAD (ablation, balanced validation) or NEO (long tail, matched validation). The 95% Student t interval uses the three seed-level means of paired corruption differences.
